🧮 Native Tensor Math

O(N²) Matrix Multiplication built from scratch. No PyTorch, no bloated dependencies. Just pure mathematical operations mapped directly to memory.

🧠 Transformer Architecture

Implements Scaled Dot-Product Self-Attention and RMSNorm exactly as used in state-of-the-art models like Llama-3.

⚡ Safetensors mmap

Bypasses RAM bottlenecks by memory-mapping (mmap) .safetensors files directly from the SSD into the inference pipeline.
